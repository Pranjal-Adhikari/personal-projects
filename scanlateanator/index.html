Scanlateanator
An image editor for manga scanlation

Desktop Required

This app is designed for desktop computers!! It requires a mouse/trackpad and keyboard for the editing features to work properly ;-;

What it does:

  • Brush tool for cleaning up images
  • Text tool with custom fonts and formatting
  • Multi-page editing and batch exports
  • Undo/redo with history timeline
  • Zoom and pan controls
Canvas with brush and text tools, layers, multi-page upload, and per-page history
Add and format text boxes

Why desktop only?

The editor needs precise mouse control for drawing, text box handles that are too small for touch screens, keyboard shortcuts for efficient editing... and I didn't design the app to be responsive so it doesn't format correctly on small screens

It's built for the same workflow as Photoshop or GIMP, both of which are also desktop-only tools.

Welcome to Scanlateanator

Upload an image to start editing. Perfect for manga scanlation, comic translation, and image editing.

The brush tool paints over your image with a selected color. Use it to clean up bubbles, clean up scans, or to redraw parts of the image. Adjust the size and color to match your needs.

The eraser removes brush strokes and edits you've made. It does not affect the original image.

The text tool lets you add editable text boxes to your image. Customize the font, size, colors, and styling. Drag top left corner to move, use handles to resize, and the top center handle to rotate.

Control the visibility of different editing layers. You are able to toggle text boxes and brush edits on or off.

Scanlateanator Help

Getting Started

Click the Upload Image button to load your manga page or comic image. The editor supports most common image formats (PNG, JPG, WebP, etc.).

Tools Overview

Brush Tool

Paint over your image with a selected color. Perfect for cleaning up speech bubbles, removing text, or covering unwanted elements.

  • Adjust size with the slider (2-120px)
  • Choose any color with the color picker
  • White is commonly used for bubble cleanup

Eraser Tool

Remove brush strokes you've made. Note: This only erases your edits, not the original image.

  • Adjust eraser size as needed
  • Use to fix mistakes or refine brush work

Text Tool

Add translated or custom text to your image.

  • Click the Text button, then click on the canvas to place a text box
  • Double-click the text to edit content
  • Move: Drag the top-left handle (northwest corner)
  • Resize: Drag any other corner or edge handle
  • Rotate: Drag the circular handle above the text box
  • Customize font, size, colors, stroke, and alignment in the sidebar

Multi-Page Management

Work on multiple pages in a single session:

  • Add Page: Click "+ Add Page" and upload a new image
  • Switch Pages: Use the dropdown to navigate between pages
  • Delete Page: Remove the current page (requires at least 2 pages)
  • Each page maintains its own edits, text, and undo history

Undo/Redo

The editor tracks up to 20 actions per page:

  • Undo: Ctrl+Z (or ⌘+Z on Mac) or click the undo button
  • Redo: Ctrl+Y or Ctrl+Shift+Z (⌘+Shift+Z on Mac)
  • View history in the left sidebar and click to jump to any state

Layers

Toggle visibility of different editing layers:

  • Text Layer: Show/hide all text boxes
  • Edit Layer: Show/hide all brush strokes
  • Useful for previewing your work or focusing on specific edits

Exporting

Save your finished work:

  • Current Page: Export the active page as a PNG
  • All Pages: Export all pages as a ZIP file (if multiple pages exist)
  • Exports combine the original image, brush edits, and rendered text into a single flattened image

Zoom and Pan

Navigate and zoom for precise editing:

  • Ctrl + Mouse Wheel: Zoom in/out (zoom follows mouse position)
  • Mouse Wheel (no Ctrl): Scroll up/down normally
  • + / - Keys: Zoom in/out
  • 0 Key: Reset to 100% zoom
  • Fit Button: Zoom to fit image in viewport
  • Spacebar + Drag: Pan around the canvas
  • Middle Mouse + Drag: Pan around the canvas
  • Zoom range: 10% to 500%

Keyboard Shortcuts

  • Ctrl+Z / ⌘+Z: Undo
  • Ctrl+Y / ⌘+Shift+Z: Redo
  • Ctrl + Wheel: Zoom in/out
  • + / =: Zoom in
  • -: Zoom out
  • 0: Reset zoom to 100%
  • Spacebar: Hold to enable pan mode

How to Use

  • Use a white brush to clean speech bubbles before adding translated text, for manga
  • Adjust the text stroke width (default 0) to make text more readable over busy backgrounds
  • Save your work by exporting. !!!! The editor doesn't auto-save !!!
  • Large images (over 4096px) are automatically resized for performance
  • Use the history panel to quickly review/undo/redo your editing steps
  • Text alignment (left/center/right/justify) helps match original layouts

Limitations

  • No auto-save - remember to export your work!!!
  • Closing the browser will lose all unsaved progress
  • Maximum 20 undo steps per page
  • Images over 4096px in either dimension are automatically scaled down for memory
